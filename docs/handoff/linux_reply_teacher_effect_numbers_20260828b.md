## 1. 一句話結論（決定措辭的關鍵）

**本血緣拿不到「有蒸餾訓練 vs 無蒸餾訓練」的對照。**

§3.7.3 自己已寫明：蒸餾第一道閘門 `corridor_teacher_distill_epochs` 預設為 0，
且 sim-to-real v2 的 SA1–SA5 血緣從未開啟。因此可取得的是
**「教師接管動作 vs 策略自駕」的控制器替換對照**。

這兩件事在論文裡措辭必須分開。若寫成「加入教師使成功率提升」會與 §3.7.3 直接矛盾。
而且——**數據本身也不支持那個方向**（見 §2 表 3.23，八格中僅一格教師勝出）。

## 4. 撰寫時必須一併陳述的四項限制

1. **不是訓練消融。** 表 3.23 量的是「教師接管動作時的表現」。
   本節不得被引用為「加入教師使策略變好」的證據。
2. **單一評測種子。** 表 3.20 與表 3.23 全部為種子 818，種子數 = 1；
   只有表 3.22 的窄縫驗收是三種子。兩者證據強度不同。
3. **教師組態與 §3.7.1 所述不一致。** 表 3.21 前六列與表 3.23 的三種教師臂
   皆使用 **R = 10**，而 §3.7.1 所述生產設定為 **R = 1**，
   且該節已記載 R = 10 被閉環 A/B 否決
   （三種子、2S1D：成功率 95.910% → 92.616%、碰撞率 4.090% → 7.384%、逾時皆 0）。
   **此註不加，第五章將與 §3.7.1 自相矛盾。**
4. **步數預算不齊。** 策略臂與無記憶教師臂 2500 步，兩組狀態機教師臂 4000 步。
   三率已正規化故可比，但回合數 n 的差異來源須於表註說明。
