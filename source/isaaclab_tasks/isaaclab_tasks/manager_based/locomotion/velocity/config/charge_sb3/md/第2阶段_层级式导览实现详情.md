# 分層式導航系統 - 完整實現指南

## 📋 概述

本文檔說明了如何在 IsaacLab 中實現完整的**分層式導航架構**，包含：

1. **上層：全域路徑規劃** - 使用 A* 或 RRT* 算法
2. **下層：局部路徑規劃** - 使用 RL (PPO) 追蹤 sub-goal
3. **底層：安全過濾器** - 使用規則或 CBF 保證安全

## 🧩 已實現的組件

### 1. 全域路徑規劃器 (`global_planner.py`)

#### A* 規劃器 (`AStarPlanner`)

```python
from hierarchical import AStarPlanner

# 創建 A* 規劃器
grid_map = GridMap(
    resolution=0.1,      # 10 cm/格子
    size_x=100,         # 100 × 100 格子
    size_y=100,
    origin=(-5.0, -5.0), # 地圖原點 (世界坐標)
)

planner = AStarPlanner(
    grid_map=grid_map,
    diagonal_movement=True,  # 允許對角線移動
)

# 規劃路徑
path = planner.plan(
    start=(0.0, 0.0),
    goal=(4.0, 4.0),
    obstacles=[...],  # 障礙物列表
)

# 獲取路徑點
for waypoint in path.waypoints:
    print(f"Waypoint: {waypoint.position}")
```

#### RRT* 規劃器 (`RRTStarPlanner`)

```python
from hierarchical import RRTStarPlanner

# 創建 RRT* 規劃器
planner = RRTStarPlanner(
    bounds=(-10.0, 10.0, -10.0, 10.0),  # 空間邊界
    max_iterations=10000,
    step_size=0.5,
    goal_sample_rate=0.1,
)

# 規劃路徑
path = planner.plan(
    start=(0.0, 0.0),
    goal=(4.0, 4.0),
    obstacles=[...],
)
```

### 2. 安全過濾器 (`safety_shield.py`)

#### 規則基礎過濾器 (`RuleBasedShield`)

```python
from hierarchical import RuleBasedShield

# 創建規則過濾器
shield = RuleBasedShield(
    safety_distance=0.8,      # 安全距離
    danger_distance=0.5,       # 危險距離
    emergency_distance=0.3,    # 緊急距離
    max_linear_speed=1.5,
    max_angular_speed=1.5,
)

# 過濾動作
safe_action = shield.filter_action(
    action=rl_action,         # RL 輸出的動作
    robot_pos=robot_pos,       # 機器人位置
    robot_vel=robot_vel,       # 機器人速度
    lidar_scan=lidar_data,     # Lidar 掃描數據
    obstacles=[...],           # 障礙物列表
)

if safe_action.safe:
    # 動作是安全的，執行
    print(f"Safe action: {safe_action.linear_speed:.2f}, {safe_action.angular_speed:.2f}")
else:
    # 動作不安全，已過濾
    print(f"Unsafe action (reason: {safe_action.reason})")
```

#### CBF 過濾器 (`CBFShield`)

```python
from hierarchical import CBFShield

# 創建 CBF 過濾器
shield = CBFShield(
    safety_distance=0.8,
    alpha=1.0,                # Class-K 函數
    max_linear_speed=1.5,
    max_angular_speed=1.5,
)

# 過濾動作
safe_action = shield.filter_action(
    action=rl_action,
    robot_pos=robot_pos,
    robot_vel=robot_vel,
    lidar_scan=lidar_data,
    obstacles=[...],
)
```

#### 複合過濾器 (`CompositeShield`)

```python
from hierarchical import CompositeShield, RuleBasedShield, CBFShield

# 創建複合過濾器
shield = CompositeShield(
    rule_shield=RuleBasedShield(),
    cbf_shield=CBFShield(),
)

# 第一層：規則過濾（快速）
# 第二層：CBF 過濾（精確）
safe_action = shield.filter_action(...)
```

### 3. 分層式導航管理器 (`hierarchical_manager.py`)

from hierarchical import (

## 🎯 分層式 vs 直接導航的對比

| 特性 | 直接導航 | 分層式導航 |
|------|---------|-----------|
| **輸入** | Lidar + 終點位置 | Lidar + sub-goal 位置 |
| **輸出** | 直接到達終點的動作 | 追蹤 sub-goal 的動作 |
| **路徑規劃** | 隱式學習 | 顯式 A*/RRT* |
| **複雜度** | 需要學會長距離規劃 | 只需學會局部追蹤 |
| **安全性** | 僅靠 RL 獎勵 | 多層安全保護 |
| **可解釋性** | 低（黑盒） | 高（路徑可視化） |
| **訓練難度** | 高（狀態空間大） | 低（任務簡化） |
| **適用場景** | 短距離導航 | 長距離、複雜環境 |

## 🔧 分層式 PPO 配置

創建專用於分層式導航的 PPO 配置：

`agents/sb3_ppo_hierarchical.yaml`

```yaml
# ==============================================================================
# 分層式導航 PPO 配置
# ==============================================================================

# 基礎配置
seed: 42
n_timesteps: !!float 3e7
policy: 'MlpPolicy'

# PPO 參數（針對分層式任務優化）
n_steps: 24
n_minibatches: 4
gae_lambda: 0.95
gamma: 0.99
n_epochs: 6
ent_coef: 0.001
learning_rate: !!float 1e-4
clip_range: !!float 0.2

# 策略網絡架構
policy_kwargs:
  activation_fn: 'nn.ELU'
  net_arch: [256, 128, 64]  # 較小（任務更簡單）
  optimizer_kwargs:
    eps: !!float 1e-8
  ortho_init: False
  vf_coef: 1.0

# 梯度裁剪
max_grad_norm: 1.0

# 觀測歸一化
normalize_input: True
normalize_value: False
clip_obs: 10.0

# 分層式導航特點：
# 1. 任務更簡單（只追蹤 sub-goal，而非終點）
# 2. 觀測空間更小（移除終點位置，改用 sub-goal）
# 3. 收斂更快（局部任務更容易學習）
# 4. 更穩定（sub-goal 距離固定）
```

## 🚀 使用示例

### 完整的分層式導航流程

```python
import gymnasium as gym
import torch
from hierarchical import create_astar_hierarchical_navigation

# 1. 創建分層式導航管理器
manager = create_astar_hierarchical_navigation(
    grid_resolution=0.1,
    sub_goal_distance=3.0,
    shield_type="composite",  # 使用複合過濾器
)

# 2. 創建環境
env = gym.make("Isaac-Navigation-Charge-Hierarchical-v0")

# 3. 重置環境
obs, info = env.reset()

# 4. 初始化導航
robot_pos = info["robot_position"]
goal_pos = info["goal_position"]
obstacles = info["obstacles"]

state = manager.reset(robot_pos, goal_pos, obstacles)

# 5. 主循環
episode_length = 0
max_episode_length = 45 * 25  # 45 秒 @ 25 Hz

while not done and episode_length < max_episode_length:
    # 獲取 sub-goal
    sub_goal = manager.get_sub_goal_relative(
        robot_pos=info["robot_position"],
        robot_yaw=info["robot_yaw"],
    )

    # RL 預測動作（輸入：Lidar + sub-goal）
    action, _ = model.predict(obs)

    # 過濾動作（安全層）
    safe_action = manager.filter_action(
        action=torch.tensor(action),
        robot_pos=torch.tensor(info["robot_position"]),
        robot_vel=torch.tensor(info["robot_velocity"]),
        lidar_scan=torch.tensor(info["lidar_scan"]),
        obstacles=info["obstacles"],
    )

    # 執行動作
    obs, reward, done, truncated, info = env.step(safe_action.to_numpy())

    # 更新 sub-goal
    manager.update_sub_goal(info["robot_position"])

    episode_length += 1

# 6. 檢查是否完成
if manager.is_complete():
    print("Navigation complete!")
else:
    print("Navigation incomplete")
```

## 📊 性能優化建議

### 1. Sub-goal 距離選擇

| sub-goal 距離 | 優點 | 缺點 | 適用場景 |
|--------------|------|------|----------|
| 1-2 米 | 追蹤精確，局部任務更簡單 | 路徑段數多，計算量大 | 寬闊環境 |
| 3-5 米 | 平衡 | 標準選項 | 大多數場景 |
| 5-8 米 | 路徑段數少，計算快 | 追蹤困難 | 狹窄環境 |

### 2. 安全過濾器選擇

| 過濾器類型 | 計算量 | 安全性 | 靈活性 | 適用場景 |
|-----------|-------|-------|-------|----------|
| Rule-based | 低 | 中 | 低 | 快速原型 |
| CBF | 高 | 高 | 中 | 需要嚴格安全 |
| Composite | 中 | 最高 | 最高 | 生產環境 |

### 3. 全域規劃器選擇

| 算法 | 時間複雜度 | 最優性 | 適用場景 |
|------|----------|-------|----------|
| A* | O(b^d) | 最優 | 靜態障礙物 |
| RRT* | O(n log n) | 漸近最優 | 動態障礙物 |

## 🐛 常見問題

### Q1: 為什麼 sub-goal 不更新？

**可能原因**：
1. sub-goal 容忍度設置太小
2. 機器人速度太慢
3. Lidar 噪音太大

**解決方案**：
```python
# 增加容忍度
manager.sub_goal_tolerance = 1.0  # 從 0.5 增加到 1.0

# 檢查速度
print(f"Robot speed: {robot_vel}")
```

### Q2: 安全過濾器頻繁觸發？

**可能原因**：
1. 安全距離設置太保守
2. Lidar 測量誤差
3. RL 學會了激進行為

**解決方案**：
```python
# 放寬安全距離
shield.safety_distance = 1.0  # 從 0.8 增加到 1.0

# 檢查 Lidar 數據
print(f"Min lidar distance: {lidar_scan.max()}")
```

### Q3: 全域規劃找不到路徑？

**可能原因**：
1. 障礙物過多
2. 起點/終點被障礙物包圍
3. 網格解析度太低

**解決方案**：
```python
# 增加網格解析度
grid_map = GridMap(resolution=0.05)  # 從 0.1 降低到 0.05

# 增加 RRT* 迭代次數
planner.max_iterations = 20000  # 從 10000 增加到 20000
```
