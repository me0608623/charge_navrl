## 核心 API

### 1. 創建管理器

```python
from isaaclab_tasks.manager_based.locomotion.velocity.config.charge_sb3.hierarchical import (
    HierarchicalNavigationManager,
)

manager = HierarchicalNavigationManager(
    env=env,
    lookahead_distance=2.0,
    replan_interval=2.0,
    enable_visualization=True,
)
```

### 2. 更新導航系統

```python
# 在每個環境步驟
debug_info = manager.update(dt=0.02)

# 調試信息包含：
# - replan_count: 重規劃次數
# - replan_reasons: 重規劃原因列表
```

### 3. 訪問局部目標

```python
# 局部目標自動存儲在環境中
local_goal = env._local_goal_world  # [num_envs, 2]
```

## 觀測空間

```python
# 完整觀測 (82 維)
observation = [
    lidar_scan,          # [72] LiDAR 掃描
    distance,             # [1]  到局部目標的距離（歸一化）
    heading_error,        # [1]  航向誤差（弧度）
    forward,              # [1]  前向分量（歸一化）
    lateral,              # [1]  側向分量（歸一化）
    linear_vel,           # [1]  線速度（歸一化）
    angular_vel,          # [1]  角速度（歸一化）
]
```

## 獎勵函數

```python
# 總獎勵
R_total = (
    10.0 * R_reach          # 抵達局部目標
    + 2.0 * R_progress       # 靠近目標
    + 0.5 * R_tracking      # 航向對齊
    - 20.0 * P_collision    # 碰撞
    - 0.1 * P_smooth        # 抖動懲罰
)
```

## 重規劃觸發條件

| 條件 | 閾值 | 說明 |
|------|------|------|
| 卡住 | 速度 < 0.1 m/s × 2s | 機器人移動太慢 |
| 偏離 | 路徑距離 > 1.5m | 偏離 AIT* 路徑太遠 |
| 無進步 | 進步 < 0.2 m/s × 3s | 長時間沒有靠近目標 |
