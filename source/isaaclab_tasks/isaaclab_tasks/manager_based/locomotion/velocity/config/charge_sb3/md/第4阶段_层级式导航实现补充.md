## 🏗️ 已實現的三層架構

### 上層：全域路徑規劃

**實現文件**：`hierarchical/global_planner.py`

**組件**：

#### 1. A* 路徑規劃器 (`AStarPlanner`)
- 算法：A* 搜索
- 適合：靜態障礙物
- 複雜度：O(b^d)，b 是分支因子，d 是深度
- 最優性：保證找到最短路徑（如果存在）

**特點**：
```python
- 網格地圖：可自定義解析度（默認 10 cm/格子）
- 對角線移動：可選（4 方向或 8 方向）
- 啟發函數：曼哈頓（4 方向）或切比雪夫（8 方向）
- 快速重規劃：使用已記錄的障礙物位置
```

#### 2. RRT* 路徑規劃器 (`RRTStarPlanner`)
- 算法：RRT* (Rapidly-exploring Random Tree Star)
- 適合：動態障礙物、連續空間
- 複雜度：O(n log n)，n 是節點數
- 最優性：漸近最優（隨著迭代次數增加）

**特點**：
```python
- 連續空間：不限於網格
- 可自定義空間邊界
- 可調整擴展步長
- 目標採樣：一定概率直接採樣目標點
- 重連線：優化已經探索的樹
```

**全局規劃器接口**：
```python
class GlobalPlanner:
    def plan(
        start: Tuple[float, float],
        goal: Tuple[float, float],
        obstacles: List[Obstacle],
        grid_map: Optional[GridMap] = None,
    ) -> Path:
        """規劃從起點到終點的路徑"""
```

### 底層：安全過濾器

**實現文件**：`hierarchical/safety_shield.py`

**組件**：

#### 1. 規則基礎安全過濾器 (`RuleBasedShield`)
- 方法：基於 Lidar 閾值的簡單規則
- 計算量：極低
- 適合場景：快速原型、調試模式

**規則**：
```python
# 距離 < 0.3m：緊急停止（速度 = 0）
# 0.3m <= 距離 < 0.5m：危險警告（速度 × 0.5）
# 0.5m <= 距離 < 0.8m：安全警告（速度 × 0.8）
# 距離 >= 0.8m：無干預
# 預測 0.5 秒後會碰撞：停止
```

#### 2. CBF 安全過濾器 (`CBFShield`)
- 方法：控制屏障函數 (Control Barrier Functions)
- 計算量：中等
- 適合場景：生產環境、需要嚴格安全保證

**數學公式**：
```
屏障函數：h(x) = d(x, obstacle) - d_safe
李導數：Lf h(x) = (x - obs) / ||x - obs|| · v
約束：Lf h(x) + α · h(x) >= 0
```

#### 3. 複合安全過濾器 (`CompositeShield`)
- 方法：多層次安全過濾
- 第一層：規則過濾（快速）
- 第二層：CBF 過濾（精確）
- 計算量：中等（第一層過濾後才計算第二層）

**優勢**：
- 快速：規則過濾器可以快速處理明顯不安全的情況
- 精確：CBF 提供更嚴格的數學保證
- 魯棒：兩層過濾提供多重保護

**安全過濾器接口**：
```python
class SafetyShield:
    def filter_action(
        self,
        action: torch.Tensor,           # RL 輸出的動作
        robot_pos: torch.Tensor,          # 機器人位置
        robot_vel: torch.Tensor,          # 機器人速度
        lidar_scan: torch.Tensor,         # Lidar 掃描
        obstacles: List[Obstacle],      # 障礙物列表
    ) -> SafetyAction:
        """過濾動作，返回安全動作"""
```

## 🔧 分層式導航管理器

**實現文件**：`hierarchical/hierarchical_manager.py`

**功能**：
```python
class HierarchicalNavigationManager:
    def reset(start, goal, obstacles) -> NavigationState
        """重置導航狀態，規劃全局路徑"""

    def update_sub_goal(robot_pos) -> bool
        """更新 sub-goal（如果到達當前 sub-goal）"""

    def get_sub_goal_relative(robot_pos, robot_yaw) -> Tuple[float, float]
        """獲取 sub-goal 的相對位置（機器人坐標系）"""

    def filter_action(rl_action, ...) -> SafetyAction
        """過濾 RL 輸出的動作（通過安全過濾器）"""

    def is_complete() -> bool
        """檢查導航是否完成（到達終點）"""

    def get_progress() -> float
        """獲取導航進度 [0, 1]"""
```

**Sub-Goal 策略**：
```python
# 選擇下一個 sub-goal 的策略：
1. 沿路徑向前選擇第一個距離大於 sub_goal_distance 的航點
2. 如果沒有這樣的航點，使用終點
3. 當機器人距離 sub-goal < tolerance 時，前進到下一個
```

## 📊 系統流程

### 完整導航流程

```
1. 初始化階段
   ├─ 輸入：起點位置、終點位置、障礙物列表
   ├─ 全域規劃：A* 或 RRT* 生成全局路徑
   └─ 初始化第一個 sub-goal

2. 主循環（每一步）
   ├─ 感知：獲取機器人位置、速度、Lidar
   ├─ Sub-Goal 更新：檢查是否到達當前 sub-goal
   ├─ 觀測更新：Lidar + sub-goal 相對位置
   ├─ RL 推理：PPO 模型輸出動作
   ├─ 安全過濾：通過安全過濾器檢查並過濾動作
   ├─ 執行動作：將過濾後的動作發送給機器人
   └─ 終止檢查：是否到達終點

3. 完成階段
   ├─ 導航完成：所有 sub-goal 都已到達
   ├─ 返回最終結果
   └─ 可選：記錄路徑、性能指標等
```

### 在環境中使用

```python
class HierarchicalNavigationEnv(ManagerBasedRLEnv):
    def __init__(self, cfg):
        super().__init__(cfg)
        
        # 初始化分層式導航管理器
        self.manager = create_astar_hierarchical_navigation()
        self.state = None

    def reset(self):
        # 調用父類重置
        obs = super().reset()
        
        # 獲取障礙物
        obstacles = self._convert_obstacles()
        
        # 重置分層式導航
        self.state = self.manager.reset(
            start=self._get_robot_pos(),
            goal=self._get_goal_pos(),
            obstacles=obstacles,
        )
        
        # 更新 sub-goal 觀測
        self._update_sub_goal_observations()
        
        return obs

    def step(self, action):
        # 安全過濾
        safe_action = self.manager.filter_action(
            action=action,
            robot_pos=self._get_robot_pos(),
            robot_vel=self._get_robot_vel(),
            lidar_scan=self._get_lidar(),
            obstacles=self._convert_obstacles(),
        )
        
        # 執行過濾後的動作
        obs, reward, done, info = super().step(safe_action.to_tensor())
        
        # 更新 sub-goal
        self.manager.update_sub_goal(self._get_robot_pos())
        self._update_sub_goal_observations()
        
        # 記錄導航進度
        info["navigation_progress"] = self.manager.get_progress()
        
        return obs, reward, done, info
```

```python
from hierarchical import AStarPlanner, GridMap, Obstacle

# 創建網格地圖
grid_map = GridMap(
    resolution=0.1,
    size_x=100,
    size_y=100,
    origin=(-5.0, -5.0),
)

# 添加障礙物

    Obstacle(position=(2.0, 1.0), size=1.0, shape="circle"),

for obs in obstacles:

# 創建規劃器
planner = AStarPlanner(grid_map, diagonal_movement=True)

# 規劃路徑
path = planner.plan(
    start=(0.0, 0.0),
    goal=(4.0, 4.0),
    obstacles=obstacles,
)

print(f"路徑：{len(path)} 個航點，總長度：{path.total_length:.2f} 米")
```

## 📈 性能優化建議

### 1. Sub-Goal 距離選擇

| sub-goal 距離 | 優點 | 缺點 | 適用場景 |
|--------------|------|------|----------|
| 1-2 米 | 追蹤精確，局部任務簡單 | 路徑段數多，計算量大 | 狹窄環境 |
| 3-5 米 | 平衡，標準選項 | - | 大多數場景 |
| 5-8 米 | 路徑段數少，計算快 | 追蹤困難 | 寬闊環境 |

### 2. 安全過濾器選擇

| 過濾器類型 | 計算量 | 安全性 | 靈活性 | 適用場景 |
|-----------|--------|-------|--------|----------|
| Rule-based | 低 | 中 | 低 | 快速原型 |
| CBF | 高 | 高 | 中 | 生產環境 |
| Composite | 中 | 最高 | 最高 | 最終部署 |

### 3. 全域規劃器選擇

| 規劃器 | 時間複雜度 | 最優性 | 適用場景 |
|---------|----------|-------|----------|
| A* | O(b^d) | 保證最優 | 靜態障礙物 |
| RRT* | O(n log n) | 漸近最優 | 動態障礙物 |
