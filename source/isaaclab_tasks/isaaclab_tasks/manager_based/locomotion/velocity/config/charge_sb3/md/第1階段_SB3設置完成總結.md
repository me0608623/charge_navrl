## 📌 關鍵提示

### 訓練建議

1. **從小開始**：先用 16-64 環境測試，確認正常後再用 128-256
2. **監控指標**：定期檢查 TensorBoard，確保訓練正常
3. **保存檢查點**：定期保存模型，避免訓練失敗後丟失進度
4. **使用不同種子**：用不同種子多次訓練，獲得更穩定的結果

### 參數調整建議

1. **先調一個參數**：一次只調整一個參數，觀察效果
2. **記錄變更**：記錄每次參數調整的原因和效果
3. **參考基準**：使用提供的基準配置作為起點
4. **逐步調整**：小幅調整參數（如學習率 ±50%）

### 故障排除建議

1. **查看日誌**：檢查 `logs/sb3/` 中的訓練日誌
2. **監控 GPU**：使用 `nvidia-smi` 監控 GPU 使用情況
3. **檢查內存**：確保系統有足夠內存
4. **重啟訓練**：遇到問題時，從檢查點恢復訓練
